# המנוע

אפליקציית ווב לאימוני כושר: בוחרים מקום וזמן, מקבלים אימון של חימום, כמה משחקונים ושחרור. כל משחקון שואל שאלה אחת, רץ מול שעון ונותן תוצאה לנצח בפעם הבאה.

- הוראות עבודה: [CLAUDE.md](CLAUDE.md)
- הצורה של אימון: [docs/CONTRACT.md](docs/CONTRACT.md)
- מה נעשה ומה נשאר: [docs/PLAN.md](docs/PLAN.md)

## הרצה מקומית

דרוש Node.js 22 ומעלה.

```sh
corepack enable
pnpm install
pnpm db:local        # מסד מקומי, משאירים פתוח בטרמינל נפרד
pnpm db:setup        # סכמה ומאגר התרגילים
pnpm dev             # http://localhost:3000
```

בפיתוח מקומי בלי `APP_PASSWORD` האפליקציה פתוחה בלי כניסה. בסביבת ענן (Codespaces): `pnpm cloud:setup`, `pnpm cloud:dev`, והסיסמה ב־`pnpm cloud:password`.

## בדיקות

```sh
pnpm typecheck
pnpm lint
pnpm test
pnpm build
```

בדיקה חיה של ה־API ושל מסך האימון בדפדפן (ניתוק, שגיאת שרת, לחיצה כפולה, אימון שנסגר). היא מוחקת את אימוני המשתמש ומשנה נתונים, ולכן רצה רק מול שרת ומסד מקומיים שאפשר לזרוק, ורק עם אישור מפורש:

```sh
# בטרמינלים נפרדים: pnpm db:local, ואז APP_PASSWORD=... pnpm dev
LIVE_CHECK=throwaway-local-data APP_PASSWORD=... DATABASE_URL=postgres://postgres@127.0.0.1:5433/postgres pnpm check:live
```

הדפדפן הוא Chromium של Playwright; אם הוא מותקן במקום אחר, `CHROMIUM_PATH` מצביע אליו.

## מקורות ורישוי

מאגר התרגילים מבוסס על מקורות פתוחים; הפירוט ב־[CREDITS.md](CREDITS.md).

## מאגר התרגילים והמיפוי

המאגר כולל 959 רשומות: 283 הרשומות הקיימות ו־676 תוספות שנבדקו ב־forceapp. אחרי `pnpm db:setup`, עורך `/admin/exercises` מציג 958 רשומות פעילות לעיון; `high-knees` נשמר לקריאת היסטוריה. ״הסבר ותמונות״ מציג גם צדדים וספירה, יחידות עומס ורכיבים, גומיות ועיגון, זווית ספסל, גובה כבל, כיוון מושב, אחיזה ותמונות מקור.

מקור התיוג הוא `data/tagging.yaml` יחד עם `data/training-types/*.yaml`; העורך בפיתוח שומר בקובץ של הרשומה ואז מייבא למסד. מיפוי הביצוע נמצא ב־`data/exercise-execution.json` ונערך בקוד. עריכת הוראות בעברית מסמנת בתצוגה שהמיפוי צריך בדיקה מחדש. פרטי המקור והגרסה המוצמדת נמצאים ב־`data/catalog-source.json`.

שתי האפליקציות עצמאיות. זהו צילום תוכן שנבדק, ללא סנכרון אוטומטי, תלות בזמן ריצה ב־forceapp או חיבור חי ל־Google Sheets. 676 התוספות מוצגות במאגר; `data/catalog-workout-policy.json` משאיר אותן מחוץ לבחירה באימון עד להחלטה על התמיכה בהן. G18 שומר את מאגר הבחירה והמגבלות הקיימים. ברירות המחדל של הציוד, החימום והשחרור נשמרו. האנגלית של התוספות נשמרה כנוסח מקור לעיון, בנפרד מהעיבוד שנבדק בעברית.

בדיקת התאמה לקריאת שינויים, ללא כתיבה או העתקה אוטומטית:

```sh
pnpm catalog:parity
# מול checkout נפרד של המקור, בגרסה המצוינת ב-catalog-source.json:
pnpm catalog:parity --source ../forceapp
# כדי לבדוק הבדלים מול גרסה חדשה שנבחרה במפורש:
pnpm catalog:parity --source ../forceapp --source-revision COMMIT_SHA
```

הבדיקה משווה את כל הרשומות, המיפויים, האנגלית, סדר המסגרות וחתימות 3,927 קובצי התמונות. שינוי מחזיר קוד יציאה 1 ומפרט אילו רשומות או קבצים השתנו. עוברים על ההבדלים ומחליטים מה להעביר בכל אפליקציה; לא דורסים את המנוע, ברירות המחדל או עריכות מקומיות כדי להשיג התאמה. החלפת המקור או חתימות הבסיס נעשית רק כחלק מעדכון תוכן שנבדק.

בדיקת מסך המאגר: `pnpm exec tsx tests/live/catalog-browser.ts` מול `pnpm cloud:dev` עם `CLOUD_DB_PORT=5550` ו־`CLOUD_APP_PORT=3220`. היא יוצרת ומוחקת משתמש בדיקה במסד המקומי בלבד; ניתן לשנות את תיקיית הפלט עם `CATALOG_BROWSER_OUTPUT`. תרגילים עם משקל, מכונות או זמן אינם מופעלים במנוע בעקבות הצגת המיפוי.
