# ארכיון מקורות עצמאי

כאן נשמרים **קובצי התוכן בפועל** והרישיונות, בנוסף לכתובות המקור. כל manifest כולל זהות מקור, מחברים, גרסה/מועד אחזור וחתימות קבצים. CC BY מחייב ייחוס; אינו ShareAlike. אין לשייך את רישיון המאמר לתמונות AI מקוריות שלנו.

מאגר Free Exercise DB המלא כולל הוראות ותצלומי-מקור כמסלולים, לצד ה-snapshot ההיסטורי המצומצם שנשמר ללא שינוי ב-data. הגרסה המלאה אוחזרה ב-17.9.2026; היא אינה מוצגת כאילו הייתה הגרסה ההיסטורית המדויקת, שלא תועדה.

קובצי המדיה ששימשו בפועל, צילומי המקור ההיסטוריים שנמצאו, תוצאות imagegen המלאות, פרומפטים וביקורות נשמרים בנפרד מהתצוגה הציבורית ב-`artifacts/content-sources/objects/`, לפי SHA-256. `artifacts/content-sources/index.json` מקשר כל קובץ למקור המקומי שלו ולתפקידו. מקורות שלא נמצאו מדווחים ב-unavailable, ללא המצאת השלמות. קובצי הבינארי הגדולים אינם ב-Git.

הרצה: `node scripts/backup-content-sources.cjs` יוצרת עותק tar.gz עצמאי ב-`backups/content-sources/`, בודקת רשימת קבצים וחותמת SHA-256. לשחזור יש לפתוח את הארכיון לתיקייה ריקה, ולאמת את hash הקבצים מול index.json לפני העתקה לפרויקט. מדובר בגיבוי **מקומי באותו מחשב**; לא בוצע גיבוי לענן או למחשב אחר.

תוכן מקורי בעברית נשמר כקובץ מקורי, עם הפרומפטים/מקורות ששימשו ליצירתו כשקיימים. פרטי מקור של תוכן חדש נשמרים גם כאשר source:null (שדה legacy המתייחס רק ל-Free Exercise DB).
