# ארכיון סוגי אימון — 17.09.2026

לבקשת המשתמש הוצאו מהמאגר הפעיל 5 תרגילי יוגה, 3 תרגילי קאפוארה ו-7 תרגילי ריקוד. קובצי ה-YAML הועברו ללא שינוי בבתים: כל השמות בעברית, ההוראות והתיוגים נשמרו. manifest.json מתעד את שמות התרגילים ואת גיבובי הקבצים לפני ההעברה.

מקורות התוכן המלאים והרישיונות נשמרים ב-data/sources. התמונות נשארות ב-public/exercises והשלבים והכיתובים ב-data/exercise-media.json, כך שאימונים היסטוריים ממשיכים להציג אותם. גלריית הארכיון נמצאת ב-artifacts/training-types/archive.html. הגלריה הראשית מציגה רק עדכוני תמונות שאינם בארכיון, ולא את כלל המאגר.

הייבוא סורק רק data/training-types ולכן אינו מייבא את הקבצים כאן. רשימת ההוצאה מבחירה קוראת את manifest.json ומסתירה גם רשומות שכבר יובאו בעבר; מזהים ויומני אימונים אינם נמחקים. ייחוס המקורות הציבורי נשמר גם לתוכן ההיסטורי. טיוטות הקאפוארה שלא אושרו מבחינת רישוי נותרו בנפרד ב-data/training-types-pending.
