# תוכנית הבנייה מחדש

המאגר הזה נפתח ב־8.10.2026 כהתחלה נקייה של "המנוע". המאגר הקודם (`avf204-del/forceapp`) נשאר כפי שהוא ומפעיל את האתר החי עד להחלפה.

## מה יש כאן היום

- **תשתית שהועתקה** מ־`forceapp@f72e32e`: כניסה (סיסמה, קוד הזמנה, גוגל), תנאים ופרטיות, שאלון בריאות, ייצוא ומחיקת חשבון, דף נחיתה, מאגר 283 התרגילים עם התמונות ועורך הניהול, מערכת העיצוב, הסכמה המלאה וסקריפטי הגיבוי.
- **ליבת אימון חדשה** (`src/core`): חוזה אחד, מתכנן, מהלך אימון, והמשחקון הראשון G18 "סבב תרגילים קבוע".
- **מסכים חדשים**: בית, תצוגה מקדימה, חימום, משחקון (מוכן, ספירה, עבודה, מנוחה, פעמון, סיום), שחרור, סיכום, חשבון.
- **לא הועתקו**: 1,465 קובצי התיעוד, קובצי ההוראות הישנים, ארבעת דורות המנוע הקודמים ומסכיהם, זירה, אתגרים, מרחב מקצועי, עולמות וכלכלת המשחק.

## לפני מעבר לייצור

- [ ] **נוסח משפטי.** תנאי השימוש ומדיניות הפרטיות נכתבו למוצר הקודם. צריך לעבור עליהם מול המוצר החדש. הכפתור "מחק חשבון" ו"ייצוא הנתונים שלי" קיימים במסך החשבון, כפי שהמסמכים מבטיחים.
- [ ] **דף הנחיתה** מתאר אימון של חמישה חלקים (חימום, כוח, אימון עצים, אירובי, שחרור). צריך נוסח חדש.
- [ ] **מסכי ניהול** שלא הועברו: לוח הפיילוט, רשימת משתמשים, מצב הגיבויים.
- [ ] **נתוני משתמשים קיימים.** הסכמה זהה, כך שאפשר לחבר את המאגר הזה למסד הקיים. אימונים שנוצרו בגרסאות הקודמות יישארו במסד ולא יוצגו עד שלב 9.
- [ ] **בדיקות אחסון.** `src/lib/workout-store.ts` נבדק דרך ה־API ובדפדפן, עדיין בלי בדיקות אוטומטיות מול מסד.
- [ ] **ניקוי עיצוב.** `tokens.css` ו־`globals.css` עדיין כוללים כללים של העולמות והמסכים הישנים.
- [ ] **שירות הגיבוי** ב־Railway: לחבר לפי `docs/ops/RAILWAY.md`.
